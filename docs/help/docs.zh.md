# SCOM-T 使用帮助

SCOM-T 是一款串口调试工具，支持串口、TCP 客户端 / 服务器连接，提供数据收发、日志分析、指令批量执行、热键与主题定制等功能。

## 快速上手

1. 在左侧「串口配置」面板选择端口、波特率，点击**打开**。
2. 在「数据发送」输入框输入指令（如 `AT`），按 **Enter** 或点击**发送**。
3. 在「日志接收」区域查看设备的响应。

> 提示：如果指令无响应，先确认结尾符是否为 `CRLF`（见「数据发送 → 结尾符」），以及波特率是否与设备一致。

## 串口连接

### 串口连接

在「串口配置」面板配置：

| 项 | 说明 |
|---|---|
| 端口 | 当前可用的串口设备列表 |
| 波特率 | 常用值 9600 ~ 921600，需与设备一致 |
| 数据位 / 校验位 / 停止位 | 通常为 8 / None / 1，按设备手册设置 |
| 流控 | None / 软件 / 硬件，按设备需求选择 |

点击**打开**建立连接；点击**关闭**断开。连接状态下可调整 **RTS / DTR** 信号电平。

### TCP 客户端

将连接类型切换为 TCP 客户端，填写**主机地址**与**端口**，连接后即可与远端 TCP 服务收发数据，收发日志同样进入日志区。

### TCP 服务器

将连接类型切换为 TCP 服务器，启动后监听本机端口。连接的客户端列表会显示在配置面板；可通过「发送面板 → 广播」或「指令网格 → 广播选中」向所有客户端推送数据。

### 串口数据时序

如果设备把一行回显拆成多个 USB 包导致日志截断（出现半个指令碎片），可在「设置 → 日志 → 串口数据时序」中调大**空闲刷新间隔**（默认 50ms）。一般无需修改。

## 数据发送

### 输入与发送

- 在输入框输入内容，按 **Enter** 发送；按 **Shift+Enter** 或 **Alt+Enter** 在输入框内插入换行（需展开输入框）。
- 点击输入框旁的「展开」图标可多行编辑。

### ASCII / HEX 模式

- **ASCII**：输入普通文本。
- **HEX**：输入十六进制字节，如 `41 54`（= `AT`），字节间可用空格分隔。
- 输入框旁提供「ASCII→HEX」「HEX→ASCII」快速互转按钮。

### 结尾符

发送时可在命令字节末尾追加结尾符，下拉框选择：

| 选项 | 字节 | 说明 |
|---|---|---|
| CRLF | `0D 0A` | 常用（AT 指令建议） |
| LF | `0A` | Unix 换行 |
| CR | `0D` | 回车 |
| None | 无 | 不追加 |

日志中会以字节形式显示实际追加的结尾符，如 `AT+QBLEINIT=2,0 [0D 0A]`。

### 自定义结尾符

在「设置 → 指令行」页签，可以十六进制字节序列定义自定义结尾符（如 `0D 0A 1A`），添加后会自动出现在**所有**结尾符下拉框中（发送面板、指令网格、热键、响应集编辑）。

### 多会话

通过顶部标签页可创建多个会话，每个会话拥有独立的串口连接与日志。

## 日志接收

### 显示模式

| 模式 | 说明 |
|---|---|
| 卡片 | 相邻同源数据合并为一张卡片，可折叠 |
| 文本 | 逐行显示 TX / RX，便于阅读与复制 |
| HEX | 十六进制转储，同时显示 ASCII 对照 |

工具栏可切换显示模式；时间戳格式可在「设置 → 日志 → 日志时间戳」中选择（仅时间 / 日期+时间 / 无）。

### 搜索

日志区支持搜索高亮，可开启**区分大小写**、**正则**、**整词**匹配，支持跳转到上一处 / 下一处匹配。

### 复制

- **局部选中**文字后复制：复制的是你选中的原文。
- **Ctrl+A 全选**后复制（或无选中直接复制）：导出完整格式化日志（`[RX] [时间戳] 内容`），并过滤空行。

### 日志管理

- **保存到文件**：将当前日志写入文本文件，可开启**实时写入**。
- **日志管理**：查看已保存日志、删除、以文本形式编辑。
- **清空**：可分别清空全部 / 已接收 / 已发送日志。

## 指令网格与批量执行

### 指令网格

每个网格行代表一条指令：

| 列 | 说明 |
|---|---|
| 发送 | 发送该行指令（也可在输入框按 Enter） |
| 指令内容 | AT 指令或自定义文本 |
| HEX | 勾选后按十六进制发送 |
| 结尾符 | 该行的结尾符（含自定义结尾符） |
| 间隔 | 发送间隔或响应等待超时（ms） |

点击行尾的箭头可展开「期望响应」配置，并采集实际响应、保存到响应集。

### 期望响应匹配

展开行后可配置**期望响应**，逐条等待设备返回，支持**文本 / 正则**匹配模式，全部匹配成功则该行标记为成功。

### 批量执行

- 勾选多行后，设置**循环次数**，点击**执行已选**批量发送。
- 可随时**停止**。
- 批量模式下，每行按配置的间隔与期望响应等待执行。

### 批量编辑器

「批量」页签提供带行号的批量编辑器：
- 粘贴多行指令自动填充到网格
- 支持 **Ctrl+F** 搜索替换、**Ctrl+Z / Ctrl+Y** 撤销重做
- 内置**正则清洗**预设（如去除时间戳、只保留 AT 指令）

### YAML 配置

「配置」页签可直接编辑 `prompts.yaml`（每行指令、HEX 模式、结尾符、超时等），支持保存 / 加载命名配置、打开配置目录。指令网格的改动会自动同步回配置文件。

### 响应集

「响应集」页签可管理一组「指令 + 期望响应」的集合，便于复用与导入到网格。

## 热键

### 内置快捷键

| 快捷键 | 作用 |
|---|---|
| Enter | 在发送框聚焦时发送命令 |
| Shift+Enter / Alt+Enter | 在发送框内插入换行 |
| Ctrl+A | 日志框全选 |
| Ctrl+F | 批量编辑器中搜索 |
| Ctrl+Z / Ctrl+Y | 批量编辑器撤销 / 重做 |

### 指令热键

在「设置 → 热键」中可为指令配置快捷键（支持 Ctrl / Alt + 任意键，输入框内也全局触发），也可将热键设为**内置动作**（如清除日志、刷新设备列表、关闭端口等）。帮助菜单「快捷键」可查看当前生效的热键对照表。

## 主题定制

在「设置 → 主题」中可深度个性化界面：

### 基础颜色

主背景、面板背景、输入框背景、主文字、次要文字、边框、强调色。

### 进阶颜色

悬停背景、占位符文字、聚焦边框、强调色的深 / 浅 / 淡化三档。

### 圆角与间距

小 / 中 / 大圆角、面板内边距、控件间距（单位 rem，随界面字号等比缩放）。

### 整体风格预设

一键切换**经典 / 现代圆润 / 扁平锐利**预设；之后手动微调任意项会标记为「自定义」。

### 字体

界面字体、等宽字体（日志）、字号（10–24px）、字重。字号会影响全局文本（含日志、指令网格、输入框）与 rem 间距的等比缩放。

> 亮 / 暗模式在「设置 → 通用」或主题页签顶部切换。

## 常见问题

**Q: 发送 AT 指令无响应或返回 ERROR？**
确认结尾符设为 CRLF，且波特率、数据位/校验/停止位与设备一致。若设备曾收到未加 `\r` 的指令，会把下一条与上一条拼接执行，导致 ERROR —— 建议始终带 CRLF 结尾符。

**Q: 日志里看到 `AT... [0D 0A]` 是什么意思？**
这是日志以字节形式显示实际追加的结尾符，代表发送时确实携带了 `0D 0A`（CRLF），不是字面文本。

**Q: 收到的日志被截断成半个指令？**
设备把一行拆成多个 USB 包时，可在「设置 → 日志 → 串口数据时序」调大空闲刷新间隔（如 100ms）。

**Q: 复制日志时间戳没有 `[ ]` 分隔？**
这是旧版本行为。新版本中，Ctrl+A 全选复制会导出 `[RX] [时间戳] 内容` 的格式化文本；局部选中则复制原文。

**Q: 修改主题字号后某些界面没变化？**
请确认使用最新版本。字号设置会影响全局文本与 rem 间距；图标大小不随字号缩放属于正常设计。

**Q: 帮助文档加载失败？**
在线帮助需要网络连接。请检查网络后点击「重试」；也可在设置中配置 `helpUrl` 指向自建镜像。

**Q: 串口打开失败或被占用？**
关闭占用该端口的其它程序；可尝试在「设置 → 通用 → 端口过滤」切换为显示全部端口。
