四段操作演示

按真实操作流程逐帧重绘，配色、字体和控件文案都取自应用本身。默认显示静态首帧，点「播放动图」才看 8 秒循环；系统偏好减少动效时保持静态。文字步骤始终可读。

连接与收发

选 MOCK 模拟串口、打开端口，发一条 AT 指令，看 TX/RX 日志与 HEX 原始字节。

8 秒 · 循环
文字步骤
  1. 端口选 MOCK · 模拟串口，点「打开端口」，状态变成「已连接」。
  2. 输入 AT+FWREAD，按 Enter 或点「发送」，日志立刻出现 TX 记录。
  3. 模拟串口回 OK；切到 HEX 模式，AA 55 01 00 00 FB AC 按真实字节显示，不再变成方块问号。

批量循环与间隔

勾选指令、设 3000ms 全局间隔，看日志按间隔逐条出现，以及停止按钮的复位。

8 秒 · 循环
文字步骤
  1. 勾选要循环执行的指令行；某行间隔留空时，沿用顶部「循环间隔」（默认 3000ms，也支持 2s 这类写法）。
  2. 点「▶ 开始」，按钮变成「■ 停止」，日志按间隔逐条出现，而不是一口气发完。
  3. 跑完最后一圈，「停止」立即复位成「开始」。

日志视图与搜索

卡片 / 文本 / 十六进制三种视图切换，搜索高亮，以及一键跟随。

8 秒 · 循环
文字步骤
  1. 卡片 / 文本 / 十六进制三种展示方式随场景切换；十六进制视图以 rawBytes 为准，带偏移列与 ASCII 列。
  2. 搜索 OK，匹配项橙色高亮，支持大小写、正则、全词。
  3. 手动往上翻页后出现「一键跟随」，点一下回到最新一条。

主题与布局

切暗色、开紧凑模式、拖拽面板排布，再切回亮色。

8 秒 · 循环
文字步骤
  1. 设置 → 主题，点「暗色模式」，背景 / 文字 / 边框 / 强调色一起切换。
  2. 打开「紧凑模式」，面板间距收紧，一屏能放更多日志。
  3. 拖拽面板自由排列，布局会保存；切回亮色后布局不变。
动图由同目录的 demos.html 与 render.mjs 生成：改文案或配色后重跑脚本即可，不需要录屏。
